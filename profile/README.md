### 🌟 About GeminiPOS

**GeminiPOS** is an enterprise-grade, cloud-powered Point of Sale (POS) and Omnichannel Commerce ecosystem designed to power independent retailers, specialty shops, dining establishments, and multi-location retail chains globally.

By combining ultra-responsive native Android point-of-sale terminals with cloud-native multi-store ERP and real-time marketplace synchronization, GeminiPOS eliminates counter downtime, unifies inventory, and accelerates omnichannel growth.

---

### 🚀 Core Ecosystem Modules

* 📱 **Android Native POS (`com.geminipos.nativepos`)**: High-performance counter cashiering with sub-second barcode scanning, hardware thermal printing, customer-facing displays, and split payments.
* 🌐 **MyStore Cloud ERP**: Centralized web back-office (`admin.geminipos.tech`) for inventory tracking across branches, real-time analytics, shift audits, and customer relationship management.
* 🔄 **Omnichannel Marketplace Sync**: Direct API integrations connecting physical store inventories with Shopee, TikTok Shop, Lazada, and official digital web storefronts.
* ⚡ **Offline-First Resilience**: Engineered with real-time replication to keep counter sales operating uninterrupted even during complete internet outages.
